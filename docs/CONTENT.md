# Content and contact editing

Update `lib/site.ts` to change the business name, displayed phone number, international phone number, WhatsApp number, default WhatsApp message and SEO text. The WhatsApp number must use the country code without `+`, spaces or a leading zero: for the supplied Pakistan number use `923278090456`.

Services, the four process steps, testimonial examples and FAQs are arrays in `app/page.tsx`. Reviews are intentionally marked as examples and should be replaced with genuine permission-based feedback.

The figures 5+ years, 500+ clients, Pakistan #1, cheapest and a 100% pass guarantee are user-supplied preview claims, not independently verified. Confirm accuracy and written guarantee terms before using them for promotion.

The consultation form opens WhatsApp with the fields a visitor enters. The visitor must review and send the message in WhatsApp. The Live Chat panel is a front-end panel that opens WhatsApp, not an integrated live-agent chat system.

`SafetyScript` is a provisional brand. Replace the name and text logo when the real identity is supplied. Do not imply official affiliation or certification without evidence.
